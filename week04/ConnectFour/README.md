# Connect Four Blazor App

This Blazor Web App implements a two-player Connect Four game.

## Run the app

```powershell
cd week04/ConnectFour
dotnet run
```

Open the HTTPS or HTTP URL printed by .NET. Select a down-arrow above a column to drop the current player's piece.

The app includes:

- horizontal, vertical, and diagonal win detection
- draw detection
- move history
- match wins and consecutive wins for each player
- configurable board and player colors
- new-round and reset-match controls
- keyboard-accessible column buttons
